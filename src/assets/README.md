# 일러스트 교체용 폴더

나중에 직접 만든 일러스트를 아래 폴더에 넣어 교체할 수 있습니다.
현재 v7은 안정성과 편의 기능 중심이라 CSS 기반 임시 일러스트를 사용합니다.

- backgrounds/: 배경 일러스트
- characters/: 엄마, 아빠, 가족, 반려동물 일러스트
- activities/: 태교 활동 아이콘
- decorations/: 하트, 잎 장식 등

권장 파일명 예시:
- backgrounds/garden.svg
- backgrounds/room.svg
- characters/mama.svg
- characters/family.svg
- activities/music.svg
- decorations/heart_leaf.svg
